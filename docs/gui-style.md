## 1. 主题：色值与字号的**唯一来源**

### 1.1 两个文件，各管一段

| 文件 | 管什么 |
|---|---|
| `gui/src/ui/theme.h` | **常量**（21 个不透明色 + 10 档字号 + 圆角/网格 ✓）、**令牌表 `kTokens[]`** ✓、`theme::styleSheet()` ✓ |
| `gui/src/ui/base_style.h` | **主样式表**（`theme::kBaseQss` ✓，里面写的是 `@token@` 而不是色值 ✓） |

**为什么 QSS 用令牌而不是直接写常量** ✗：QSS 是字符串，`constexpr const char*` **不能**做字面量拼接 ✗
⇒ 所以色值在 QSS 里写成 `@text@` ✓，由 `styleSheet()` 按令牌表替换 ✓。

### 1.2 三条硬规矩

1. **色值只许出现在 `theme.h`** ✗ —— 其它文件一律 `theme::kX` ✓ 或令牌 ✓
   （守卫 `test_style_guard` R1 会扫 ✓，且**跳过注释行** ✓ —— 注释里提色值不算违规 ✓）；
2. **字号只许写成令牌** ✓（`font-size: @font_md@px` ✓）—— 不许出现 `font-size: 15px` ✗（守卫 R2 ✓）；
3. **裸 `QColor(0x…)` 只许在白名单里** ✓，而且是**逐文件计数**（守卫 R3 ✓）：
   现在允许 `ui/video_panel.cpp` **6** 处 + `main_window.cpp` **1** 处（= 7 ✓）。
   ⚠ **清掉一处就必须把白名单改小** ✓，否则守卫会红 ✓ —— 这是**棘轮**：只许变紧 ✓。

### 1.3 改样式的正确姿势（以及为什么不能用截图验收 ✗）

```bash
# 1) 改 theme.h 的常量（或 kTokens 里的值）
# 2) 若改了「生成的样式表」内容 ⇒ 黄金值必须同步更新：
#    改 gui/tests/test_theme.cpp 里的 kGoldenLength / kGoldenSha256
# 3) 宿主验收：
cmake -S gui -B build-gui-host -DGUI_BUILD_TESTS=ON && cmake --build build-gui-host -j4
QT_QPA_PLATFORM=offscreen ctest --test-dir build-gui-host        # 当前 28 项，必须全绿 ✓
```

⚠ **不要用"四页截图逐像素一致"当判据** ✗✗ —— 2026-10-05 实测：宿主 offscreen **连跑两次、什么都不改**，
四页的字节数与 sha256 **全都不一样** ✗（顶栏有时钟 ✓、渲染与 PNG 编码本身不确定 ✓）；
而且宿主**没装 CJK 字体**，截图里中文全是"豆腐块"□□□ ✗。
⇒ 判据用 **`test_theme` 的黄金串**（长度 + sha256 ✓，是"输入字符串逐字节相同"的**构造性证明** ✓）；
截图只当 **rc=0 冒烟** ✓。**要看真界面必须上板** ✓（`--page <页> --screenshot` ✓，板上有思源黑体 ✓）。
